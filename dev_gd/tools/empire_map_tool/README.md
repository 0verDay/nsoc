# Empire Map Editor 使用手册

帝国地图编辑器，用于可视化绘制节点地图并导出为 JSON 数据。

## 运行方式

需要 Python 3 + tkinter（标准库自带）：

```bash
python empire_map_editor.py
```

---

## 界面说明

| 区域 | 说明 |
|------|------|
| 顶部工具栏 | 显示快捷键提示及功能按钮 |
| 主画布 | 深色背景，带网格参考线；虚线矩形为 1920×1080 参考框 |

---

## 图形类型

| 图形 | 形状 | 颜色 | 说明 |
|------|------|------|------|
| Triangle（三角形）| 三角形 | 绿色 | 用于表示地形/特殊节点 |
| Circle（圆形）| 圆形 | 蓝色 | 通用节点 |
| Square（方形）| 正方形 | 橙色 | 城市/据点节点，**必须**分配类别才能导出 |

---

## 操作快捷键

### 创建图形

按住对应数字键，然后在空白处**左键单击**：

| 按键 | 创建图形 |
|------|----------|
| `1` + 左键 | 三角形 |
| `2` + 左键 | 圆形 |
| `3` + 左键 | 方形 |

> 点击已有图形上方不会创建新图形，而是选中该图形。

### 视图控制

| 操作 | 效果 |
|------|------|
| 鼠标滚轮上滚 | 以鼠标为中心放大 |
| 鼠标滚轮下滚 | 以鼠标为中心缩小 |
| 空白处左键拖拽 | 平移视图 |

缩放范围：`0.1x` ~ `10.0x`。

### 移动图形

在图形上**左键拖拽**即可移动。

### 连接图形

依次**单击**两个图形（不拖动），即在两者之间创建连线。  
同一对图形之间只能有一条连线。

### 删除连线

**单击**连线（点击误差范围 6 像素），连线立即删除。

### 删除图形

先**单击选中**图形（图形高亮为金黄色边框），再按 `Delete` 或 `BackSpace` 键删除。  
与该图形相连的所有连线也会同步删除。

### 取消选中

单击空白处取消当前选中状态。

---

## 方形类别设置

方形节点代表城市/据点，**导出前必须为每个方形指定类别**。

| 操作 | 效果 |
|------|------|
| `1` + 右键（方形上）| 设为"大"（大城市）|
| `2` + 右键（方形上）| 设为"商"（商业城市）|
| `3` + 右键（方形上）| 设为"农"（农业城市）|
| `4` + 右键（方形上）| 设为"军"（军事城市）|
| 右键（方形上，不按数字键）| 清除类别 |

已设置类别的方形中央会显示对应汉字标签。

---

## 工具栏按钮

### Export JSON（导出）

将当前地图保存为 JSON 文件。导出前会进行两项检查：

1. **类别检查**：所有方形必须已设置类别，否则提示未分类的图形 ID。
2. **连通性检查**：所有图形必须组成一张连通图，否则提示孤立图形的 ID。

导出时坐标会自动归一化，以最左上角图形为原点 `(0, 0)` 偏移。

### Import JSON（导入）

从 JSON 文件加载已有地图，**会清空当前画布**。

### Clear All（清空）

清空所有图形和连线，同时重置 ID 计数器。操作前会弹出确认对话框。

## JSON 格式说明

```json
{
  "shapes": [
    { "id": 1, "kind": "triangle", "x": 0.0, "y": 0.0 },
    { "id": 2, "kind": "circle",   "x": 150.0, "y": 80.0 },
    { "id": 3, "kind": "square",   "x": 300.0, "y": 0.0, "category": 1 }
  ],
  "connections": [
    { "from": 1, "to": 2 },
    { "from": 2, "to": 3 }
  ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 图形唯一 ID |
| `kind` | string | `"triangle"` / `"circle"` / `"square"` |
| `x` / `y` | float | 世界坐标（导出时已归一化） |
| `category` | int \| null | 仅方形有此字段：1=大，2=商，3=农，4=军 |
| `from` / `to` | int | 连线两端图形的 ID |

---

## 参考坐标系

画布中虚线矩形对应游戏分辨率 **1920×1080**，原点 `(0,0)` 在矩形左上角。  
可将图形布局于此矩形内以对应游戏实际显示区域。
