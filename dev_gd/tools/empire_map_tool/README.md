# Empire Map Editor 使用手册

帝国地图编辑器，用于可视化绘制节点地图并导出为 JSON 数据，供 `dev_gd/nsoc/data/empire_maps/` 目录使用。

## 运行方式

需要 Python 3 + tkinter（标准库自带）：

```bash
python empire_map_editor.py
```

---

## 界面说明

| 区域 | 说明 |
|------|------|
| 顶部工具栏 | 显示快捷键提示及功能按钮 |
| 主画布 | 深色背景，带网格参考线；虚线矩形为 1920×1080 参考框 |

---

## 图形类型

| 图形 | 形状 | 对应地点类型 |
|------|------|------|
| Triangle（三角形）| 三角形 | 关隘 |
| Circle（圆形）| 圆形 | 村镇 |
| Square（方形）| 正方形 | 城市（大都市/商业/农业/军事）|

城市图形的颜色由其所属**势力**决定。

---

## 操作快捷键

### 创建图形

按住对应数字键，然后在空白处**左键单击**：

| 按键 | 创建图形 |
|------|----------|
| `1` + 左键 | 三角形（关隘）|
| `2` + 左键 | 圆形（村镇）|
| `3` + 左键 | 方形（城市）|

> 点击已有图形时不会创建新图形，而是选中该图形。

### 视图控制

| 操作 | 效果 |
|------|------|
| 鼠标滚轮上滚 | 以鼠标为中心放大 |
| 鼠标滚轮下滚 | 以鼠标为中心缩小 |
| 空白处左键拖拽 | 平移视图 |

缩放范围：`0.1x` ~ `10.0x`。

### 移动图形

在图形上**左键拖拽**即可移动。

### 连接图形

依次**单击**两个图形（不拖动），即在两者之间创建连线。  
同一对图形之间只能有一条连线。

### 删除连线

**单击**连线（点击误差范围 6 像素），连线立即删除。

### 删除图形

先**单击选中**图形（图形高亮为金黄色边框），再按 `Delete` 或 `BackSpace` 键删除。  
与该图形相连的所有连线也会同步删除。

### 取消选中

单击空白处取消当前选中状态。

---

## 地点属性编辑

**双击**任意图形，弹出「地点属性」窗口，可编辑：

| 属性 | 说明 |
|------|------|
| 地点名字 | 为该地点命名，显示在图形正下方 |
| 地点类型 | 更改后同步修改图形形状与 category |
| 资金产出 | 每回合产出的资金数量（`gold`）|
| 粮食供应 | 该地点提供的粮食数量（`food`）|
| 所属势力 | 从当前势力列表中选择（影响节点颜色）|

地点类型可选项：

| 选项 | 对应图形 |
|------|----------|
| 关隘 | 三角形 |
| 村镇 | 圆形 |
| 大都市 | 方形（category = 1）|
| 商业城市 | 方形（category = 2）|
| 农业城市 | 方形（category = 3）|
| 军事城市 | 方形（category = 4）|

点击**确定**后属性立即生效并刷新画布；点击**取消**放弃所有修改。

---

## 方形类别快捷设置

除属性窗口外，也可用快捷键直接设置方形类别：

| 操作 | 效果 |
|------|------|
| `1` + 右键（方形上）| 设为"大"（大都市）|
| `2` + 右键（方形上）| 设为"商"（商业城市）|
| `3` + 右键（方形上）| 设为"农"（农业城市）|
| `4` + 右键（方形上）| 设为"军"（军事城市）|
| 右键（方形上，不按数字键）| 清除类别 |

已设置类别的方形中央会显示对应汉字标签。

---

## 势力管理

点击"**势力管理**"按钮打开势力管理器：

- **中立**（id=0，灰色 `#808080`）为内置势力，不可删除，名称不可修改
- 点"新增势力"输入名称并选色，id 自动递增
- 可重命名、重新着色或删除自定义势力
- 每个地点可在属性窗口中选择所属势力；地点节点颜色实时跟随势力颜色变化

势力数据包含在导出 JSON 的 `factions` 字段中。

---

## 工具栏按钮

### Export JSON（导出）

将当前地图保存为 JSON 文件。  
导出时坐标会自动归一化，以最左上角图形为原点 `(0, 0)` 偏移。

### Import JSON（导入）

从 JSON 文件加载已有地图，**会清空当前画布**。地点名字、资金、粮食、势力、类别等属性均会还原。

### Clear All（清空）

清空所有图形和连线，同时重置 ID 计数器。操作前会弹出确认对话框。

---

## JSON 格式说明

```json
{
  "factions": [
    {"id": 0, "name": "中立", "color": "#808080"},
    {"id": 1, "name": "Ap",   "color": "#FF0000"},
    {"id": 2, "name": "Bp",   "color": "#0080FF"}
  ],
  "shapes": [
    {"id": 1, "kind": "triangle", "x": 0.0,   "y": 0.0,  "name": "北关", "gold": 0, "food": 0, "faction": 1},
    {"id": 2, "kind": "circle",   "x": 150.0, "y": 80.0, "name": "荒村", "gold": 2, "food": 2, "faction": 0},
    {"id": 3, "kind": "square",   "x": 300.0, "y": 0.0,  "name": "洛阳", "gold": 5, "food": 3, "faction": 2, "category": 1}
  ],
  "connections": [
    {"from": 1, "to": 2},
    {"from": 2, "to": 3}
  ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `factions` | 数组 | 势力表；id=0 固定为中立 |
| `id` | int | 图形唯一 ID |
| `kind` | string | `"triangle"` / `"circle"` / `"square"` |
| `x` / `y` | float | 世界坐标（导出时已归一化） |
| `name` | string | 地点名（可为空）|
| `gold` | int | 资金产出（每回合）|
| `food` | int | 粮食供应 |
| `faction` | int | 所属势力 id（0=中立）|
| `category` | int | 仅方形有此字段：1=大都市、2=商业、3=农业、4=军事 |
| `from` / `to` | int | 连线两端图形 ID |

## 参考坐标系

画布中虚线矩形对应游戏分辨率 **1920×1080**，原点 `(0,0)` 在矩形左上角。  
可将图形布局于此矩形内以对应游戏实际显示区域。

## 与 Godot 集成

导出的 JSON 放入 `dev_gd/nsoc/data/empire_maps/`，在 `scripts/ui/empire_test.gd` 修改常量：

```gdscript
const MAP_PATH := "res://data/empire_maps/your_map.json"
```

地图加载、渲染与势力颜色映射由 `EmpireTest._load_map()` 自动处理。

## 工具栏按钮

### Export JSON（导出）

将当前地图保存为 JSON 文件。导出前会进行两项检查：

1. **类别检查**：所有方形必须已设置类别，否则提示未分类的图形 ID。
2. **连通性检查**：所有图形必须组成一张连通图，否则提示孤立图形的 ID。

导出时坐标会自动归一化，以最左上角图形为原点 `(0, 0)` 偏移。

### Import JSON（导入）

从 JSON 文件加载已有地图，**会清空当前画布**。地点名字、资金产出、粮食供应等属性会一并还原。

### Clear All（清空）

清空所有图形和连线，同时重置 ID 计数器。操作前会弹出确认对话框。
